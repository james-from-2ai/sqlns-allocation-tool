# Site images

Place the Evidence Action logo here as `logo.svg` (or `logo.png`) and it appears
in the hero automatically.

- Rendered at 30px tall on a dark navy panel, so a **white or light monochrome**
  version reads best.
- SVG preferred. A transparent PNG at 60px tall or more is fine.
- If `logo.svg` is absent the hero simply omits it, with no broken image.

No logo is committed to this repo. It is a trademark and this repository is
public, so the asset should be added deliberately by someone who can confirm the
correct version and its usage terms.
